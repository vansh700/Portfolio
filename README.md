# Portfolio Platform

This repository contains a **full‑stack portfolio platform** for a Computer Science Engineering student.

- **Frontend** – Next.js 15, TypeScript, TailwindCSS, Shadcn UI
- **Backend** – Express, TypeScript, Prisma (PostgreSQL), Redis, Cloudinary
- **Features** – Portfolio, Blog, Projects, Expense & To‑Do managers, Coding dashboard, Admin panel, etc.

The project follows a clean‑architecture layout and includes Docker, CI/CD, and deployment scripts.

## Getting Started
```bash
# Clone the repo (already done)
# Install dependencies
cd backend && npm install
cd ../frontend && npm install

# Setup environment variables (see .env.example)

# Run locally
cd backend && npm run dev
cd ../frontend && npm run dev
```

See the `frontend/` and `backend/` directories for detailed README files.
